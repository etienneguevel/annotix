# Refactoring Plan: Merge spec2mol into graphtransf + Reorganize Package

## Context

The `spec2mol/` package is ~90% duplicated from `graphtransf/` (training loop, dataset, collator, `smilesToGraph`). Data modules are scattered across `graphtransf/data/` and `spec2mol/data/`. This refactoring centralizes data, dissolves `spec2mol/`, and lifts training to a top-level module. **`spectraencoder/` is NOT touched.**

**Target structure:**
```
annotix_ml/
├── data/            # merged from graphtransf/data + spec2mol/data
├── distributed/     # unchanged
├── graphtransf/     # arch + layers + math + models (includes spec2mol arch)
│   ├── arch/        # digress_meta_arch.py + spec2mol_meta_arch.py
│   ├── layers/
│   ├── math/        # + spec2mol_extra_features.py
│   ├── models/
│   └── test_utils.py
├── spectraencoder/  # UNCHANGED (model/, data/, utils.py all stay)
├── train/           # train_digress.py, train_spec2mol.py, setup.py, generate_molecules.py
```
