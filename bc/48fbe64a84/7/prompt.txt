Both modules share the same DiGress backbone; keeping them in sync prevents bugs and keeps maintenance overhead low.

#### i) Fix LinAlgError skip to be DDP-coordinated
Replace bare `continue` on `LinAlgError` with:
```python

    pN, pE, loss = spec2mol.forward_backward(...)
    skip = torch.zeros(1, device=device)

    pN, pE, loss = None, None, None
    skip = torch.ones(1, device=device)

if dist.is_enabled():
    torch.distributed.all_reduce(skip, op=torch.distributed.ReduceOp.MAX)
if skip.item():
    optimizer.zero_grad()
    continue
```
