## Issues Found

### 1. `forward_backward` — critical DDP bug (line 472)
Currently the `else:` branch is reached for both "no distributed" and "data parallel" cases, and
calls `self.diffuser(...)` directly. For DDP this bypasses the DDP wrapper entirely — no gradient
all-reduce happens, so each rank trains an independent copy of the model.

**Fix:** Add an `elif self.train_model is not None:` branch that calls `self.train_model(...)` (the
DDP wrapper), which registers the backward hook that triggers all-reduce on `loss.backward()`.

```
if self.train_schedule:          # pipeline parallelism — existing
    ...
elif self.train_model is not None:   # NEW: data parallelism
    N_noised, E_noised, sampled_t = self.noiser(nodes, edges, mask)
    pos_emb, y = self.compute_extra_features(N_noised, E_noised, mask, sampled_t, **kwargs)
    out = self.train_model(E_noised, mask, y, pos_emb, N_noised)
    pN, pE, *_ = out
    loss = digress_loss(pN, pE, nodes, edges, mask, self.loss_ratio)
    loss.backward()
else:                            # no distributed — existing
    ...
```

### 2. `forward` — TODO can be removed (line 408)
`forward()` is only called during eval / generation (`torch.no_grad()`). For DDP, calling
`self.diffuser` directly is correct — no gradient sync is needed. The `else:` branch already
handles DP correctly. The TODO comment should be removed (or replaced with a clarifying comment).

### 3. `_setup_distributed` — wrong `device_ids` for DDP (line 706)
```python
self.train_model = DDP(self.diffuser, device_ids=[self.rank])
```
`self.rank` is the **global** rank. `device_ids` must be **local** GPU IDs. On a 2-node × 2-GPU
setup, rank 2 has local_rank=0 (GPU 0), but `device_ids=[2]` would crash or target the wrong GPU.

**Fix:** Use `get_local_rank()` (already available from `annotix_ml.distributed`).

```python
from annotix_ml.distributed import get_global_rank, get_local_rank, is_main_process
...
self.train_model = DDP(self.diffuser, device_ids=[get_local_rank()])
```

### 4. `train.py:main()` — direct attribute access (line 561)
```python
if cfg.train.distributed == "pipeline":
```
If `distributed` is absent from the config, OmegaConf raises `ConfigAttributeError`. Every other
access in the file uses `cfg.train.get("distributed")`. Fix to be consistent.

**Fix:**
```python
if cfg.train.get("distributed") == "pipeline":
```

### 5. `train.py` — missing `is_main_process()` check on final model save (line 544)
The intermediate checkpoint save (line 523) correctly wraps `torch.save` in `dist.is_main_process()`,
but the **final** save does not. In DP mode all ranks race to write `final.pt`.

**Fix:** Add the guard:
```python
else:
    if dist.is_main_process():
        torch.save(
            digress.diffuser.state_dict(),
            os.path.join(cfg.train.save_path, "final.pt"),
        )
```
